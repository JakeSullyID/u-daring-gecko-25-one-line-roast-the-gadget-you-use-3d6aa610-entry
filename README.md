# One-Line Roast: The Gadget You Use Every Day

This entry for the make.fun bounty targets the ubiquitous robotic vacuum cleaner—specifically, its mysterious talent for endless navigational loops and dramatic entrapment under low furniture. 

> "My Roomba spends twenty minutes aggressively headbutting the exact same table leg before committing suicide under the couch."

## How to Run

Execute the program with Node.js:

```bash
node main.ts
```

The script writes the roast line to `entry.txt` inside the directory specified by the `MAKEFUN_OUTPUT_DIR` environment variable, defaulting to `/output` if not set.
